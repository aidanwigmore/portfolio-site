Setup Commands
npm create-react-app . --template typescript
npm install axios
npm install --save-dev @types/react
npm install --save-dev @types/react-dom

npm install --save-dev @typescript-eslint/parser@^5.5.0 eslint-config-prettier

how to run (if it doesn't run automatically when opening the project)

Option 1: Press Ctrl+Shift+B (or Terminal → Run Task) and select "Run All"
Option 3: Use the Command Palette (Ctrl+Shift+P) → Tasks: Run Task → Run All
